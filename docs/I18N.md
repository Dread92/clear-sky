# Translations (EN / UK / FR)

Every string the user can see lives in `static/i18n.js`. The page is fully translated in English,
Ukrainian and French — including place names, raions, Kyiv districts, rivers, airports and channel
names.

## How it works

```js
t('d_ok')                       // → "I understand" / "Зрозуміло" / "J'ai compris"
t('lbl_to', 'Kyiv', 42)         // → "→ Kyiv 42 km"   ({0}, {1} are the arguments)
tn('raion_red', 3)              // → plural: "3 raions red" / "3 райони червоні"
```

- `t(key, ...args)` — a string, with `{0}`, `{1}` placeholders. Falls back to English if a key is
  missing in the current language.
- `tn(key, n)` — plural forms. English and French use `key_1` / `key_n`; Ukrainian additionally uses
  `key_2` (2–4) and `key_5` (5+, and 11–14), following the real rule.
- `oblName(uid)` / `oblFull(uid)`, `raionName(r)`, `townName(n)`, `riverName(n)`, `poiName(n)`,
  `bridgeName(n)` — geographic names per language.
- `pn(place)` — a place name that came **from a post**: kept in Ukrainian for the Ukrainian UI,
  transliterated otherwise.

Static markup is translated by attribute, so HTML stays readable:

```html
<button data-t="m_obl">My oblast…</button>        <!-- textContent -->
<p data-t-html="d_p1"></p>                        <!-- innerHTML, for strings with <b> -->
<button data-t-title="t_center">◎</button>        <!-- title attribute -->
<input data-t-ph="h_ph">                          <!-- placeholder -->
```

## Choosing the language

Detected from the browser on first open (`uk`/`ru` → Ukrainian, `fr` → French, anything else →
English), then changeable from the flags in the disclaimer (🇬🇧 EN · 🇺🇦 UA · 🇫🇷 FR) or from
*Language* in the menu. The choice is stored per device in `localStorage` and the page reloads.

## Post text is not UI text

Posts are shown in the original Ukrainian in Ukrainian mode. In English and French they are translated
by `translate.py`: the offline glossary at once, then a machine translation (DeepL or Google Cloud, with a
key) replaces it in the background, only for a language somebody is reading. French has no offline
glossary: without a machine translator it shows the English. On the Light page a tapped row shows the
original under the translation. Details: [TECHNICAL.md §8](TECHNICAL.md#8-translation).

## Adding a string

1. Add the key to all three blocks in `static/i18n.js` — `en`, `uk`, `fr`.
2. Use it: `t('my_key')` in JavaScript, or `data-t="my_key"` in markup.
3. CI fails if a key exists in `en` but is missing from `uk` or `fr`.

## Adding a language

Add a block to `I18N` and an entry to `LANGS`, `LFLAG` and `LCODE`, add the language's column to
`OBL_N`, `RAION_N` and the other name tables (the index comes from `LI()`), and set `LOCALE()`.
Nothing else in the page needs to change.
